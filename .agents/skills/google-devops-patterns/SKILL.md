# google-devops-patterns

A skill for senior DevOps engineers working with Google Cloud and DevOps patterns.

## Description

This skill provides guidance on Google-style CI/CD pipelines, infrastructure as code, cloud-native patterns, and DevOps best practices using Google Cloud technologies. It helps engineers design, implement, and optimize reliable, scalable, and secure systems on Google Cloud Platform (GCP).

## What This Skill Helps With

- **Google-style CI/CD**: Cloud Build pipelines, Kaniko, Artifact Registry, and progressive delivery patterns
- **Infrastructure as Code**: Terraform best practices, Google Cloud Deployment Manager, and configuration management
- **Cloud Native Patterns**: Service mesh (Istio/Envoy), observability (OpenTelemetry, Prometheus, Grafana), and distributed tracing
- **DevOps Best Practices**: SRE principles, error budgeting, SLIs/SLOs, canary deployments, and blue-green strategies
- **Google-Recommended Patterns**: Twelve-factor apps, GitOps with Cloud Deploy, and automated rollouts

## Target Audience

Senior DevOps engineers and site reliability engineers working with Google Cloud who want to implement industry-standard DevOps patterns and improve their cloud operations capabilities.

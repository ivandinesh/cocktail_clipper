# CocktailClips

CocktailClips is a local-first video workspace for turning long-form media into separate, branded vertical clips. Import a local MP4 or a YouTube video, bring in an SRT transcript, paste a timestamped clip plan generated by an AI assistant, and render each selected moment as its own 9:16 MP4.

## What it does

- Imports local MP4 files with an optional SRT transcript.
- Imports public YouTube videos with video/audio merging through yt-dlp and FFmpeg.
- Detects and downloads available YouTube captions, preferring manual captions over automatic captions.
- Accepts timestamped JSON clip plans from ChatGPT, Claude, Gemini, or another AI tool.
- Validates timestamps and batch-cuts source footage with FFmpeg.
- Uses one shared opening image and one shared closing image for every clip in a project.
- Renders each clip separately as `opening image → clip → closing image`.
- Plays rendered clips inside the app and offers explicit MP4 and SRT downloads.
- Stores project media and output locally under `backend/projects/`.

## Workflow

1. Create a project from a local MP4 or public YouTube URL.
2. Add or import the transcript. YouTube captions can be saved automatically as `source.srt`.
3. Give the transcript to your preferred AI assistant and ask it for the strongest timestamped moments.
4. Paste or upload the returned JSON plan.
5. Review the ranges and cut all clips.
6. Upload project-wide 9:16 opening and closing images. Both default to 1.5 seconds.
7. Render one clip or all clips.
8. Preview clips in the app or download them from `final/clips/`.

There is intentionally no sequence-building or combined-reel step in the primary workflow. Each clip is an independent deliverable.

## Requirements

- Python 3.11 or newer
- Node.js 18 or newer
- FFmpeg and FFprobe available on `PATH`
- Git

FFmpeg is required for cutting, normalization, audio/video merging, branding, and final rendering. The Python `ffmpeg-python` package is only a wrapper and does not install the FFmpeg executable.

Verify the executables before starting:

```powershell
ffmpeg -version
ffprobe -version
```

## Development setup

### Backend

Open PowerShell in the repository root:

```powershell
cd C:\path\to\cocktail_clipper\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

If `.venv` already exists, do not recreate it—activate it and start Uvicorn.

### Frontend

Open another PowerShell window:

```powershell
cd C:\path\to\cocktail_clipper\frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). Keep both terminals running.

## YouTube import

The URL importer currently supports YouTube only. Paste a public YouTube video URL on the Import Media screen, wait for metadata, select a quality, and choose whether to import captions.

Supported quality presets are Best, 1080p, 720p, and 480p. yt-dlp selects compatible streams and FFmpeg merges separate video and audio into the project's `source.mp4`.

Private, age-restricted, members-only, region-restricted, or authentication-protected videos may not import. Only download media you have permission to use.

## Project files

Each project is stored under `backend/projects/<project-id>/`:

```text
project.json
source.mp4
source.srt                 # optional
assets/
  opening.png              # extension may vary
  closing.png
clips/
  001.mp4
  002.mp4
rendered/
  individual/
final/
  clips/
    001.mp4
    002.mp4
```

Generated project directories and media files are ignored by Git.

## Clip-plan format

The importer accepts a top-level `clips`, `scenes`, or `segments` array. A minimal plan looks like this:

```json
{
  "clips": [
    {
      "id": "001",
      "start": "00:00:25.000",
      "end": "00:00:53.000",
      "title": "A strong opening moment",
      "hook": "Why this moment matters",
      "next_hook": "Follow for the next insight"
    }
  ]
}
```

Timestamps use `HH:MM:SS.mmm`.

## API overview

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/projects/create` | Create a project from local MP4/SRT files |
| `POST` | `/imports/metadata` | Inspect a YouTube URL without downloading it |
| `POST` | `/imports/start` | Start a background YouTube import |
| `GET` | `/imports/{job_id}` | Poll YouTube import progress |
| `POST` | `/projects/import-scenes` | Import and normalize an AI clip plan |
| `POST` | `/projects/{id}/cut-all` | Cut every planned clip |
| `POST` | `/projects/{id}/branding` | Save shared opening/closing artwork and durations |
| `POST` | `/projects/{id}/render-clips` | Render selected clips separately |
| `GET` | `/projects/{id}/clips/{clip_id}/rendered-preview` | Stream a branded clip inline |
| `GET` | `/projects/{id}/clips/{clip_id}/download` | Download a branded clip |
| `GET` | `/projects/{id}/transcript/download` | Download the project's SRT transcript |

## Troubleshooting

| Problem | Resolution |
| --- | --- |
| `[WinError 2]` while cutting or rendering | Ensure `ffmpeg -version` works in the same terminal used to start Uvicorn, then restart the backend. |
| YouTube import dependency missing | Activate the backend virtual environment and run `pip install -r requirements.txt`. |
| Video has no sound | Check the source with FFprobe; the source must contain an audio stream. |
| `localhost:5173` does not load | Start the Vite frontend and use the URL printed in its terminal. |
| Backend requests fail | Start Uvicorn on port 8000 and restart Vite after proxy configuration changes. |

## Privacy

Local uploads, project JSON, cut clips, branding assets, and rendered outputs remain in the local project directory. YouTube imports contact YouTube through yt-dlp to retrieve the selected source media and captions; the resulting project files are then processed locally.

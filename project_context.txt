# CocktailClips — Local AI Video Clipper (React + FastAPI + FFmpeg)

Build a complete local application called **CocktailClips** that automatically cuts and prepares short-form videos from a source video and transcript (SRT).

## Tech Stack

* Frontend: React + Vite + Tailwind CSS.
* Backend: FastAPI (Python 3.11+).
* Video processing: FFmpeg.
* Subtitle processing: pysubs2.
* No cloud services. Everything runs locally.
* Backend exposes REST APIs used by the frontend.

## Core Architecture

The application uses **one master project JSON** as the single source of truth.

Every tool updates this JSON instead of creating separate metadata files.

Project structure:

```text
cocktailclips/
├── frontend/
├── backend/
├── projects/
│   └── my-project/
│       ├── source.mp4
│       ├── source.srt
│       ├── project.json
│       ├── clips/
│       └── final/
├── assets/
│   ├── logo.png
│   ├── intro.png
│   └── outro.png
```

## Master project.json

```json
{
  "project": {
    "id": "podcast-001",
    "name": "Episode 12 - AI Podcast"
  },
  "source": {
    "video": "source.mp4",
    "subtitle": "source.srt"
  },
  "branding": {
    "channel": "CocktailClips",
    "intro_duration": 2,
    "outro_duration": 2,
    "outro_text": "Follow for Part 2"
  },
  "clips": [
    {
      "id": "001",
      "start": "00:02:13.500",
      "end": "00:02:42.800",
      "title": "He accidentally revealed the secret.",
      "hook": "You won't believe what he admitted...",
      "next_hook": "Part 2 explains why this happened.",
      "transcript": "Transcript for only this clip.",
      "clip_file": null,
      "final_file": null,
      "status": "planned"
    }
  ]
}
```

This JSON is edited by the UI and backend.

## Feature 2 — AI Scene Import

User uploads an AI-generated JSON containing scenes.

Example:

```json
{
  "clips": [
    {
      "start": "...",
      "end": "...",
      "title": "...",
      "hook": "...",
      "next_hook": "..."
    }
  ]
}
```

Backend merges scenes into project.json.

No video processing here.

---

## Feature 3 — Clip Cutter

Reads project.json.

For each clip:

* Cut source video with FFmpeg.
* Save clips/001.mp4.
* Extract transcript lines from SRT between start/end.
* Store transcript inside project.json.
* Update clip_file.
* Update status = "cut".

No intro/outro or subtitles burned into video.

This tool should be reusable for any project.

---

## Feature 4 — Stitch / Branding Tool

Reads project.json.

For every clip:

* Add 2-second intro card.
* Intro uses hook text.
* Background is intro.png or solid black.
* Add channel logo if available.
* Burn subtitles only if clip does not already contain subtitles.
* Use transcript stored in project.json.
* Subtitle style:

  * White text.
  * Black outline.
  * Bottom centered.
  * TikTok/Shorts style.
* Add outro card.
* Outro displays next_hook text.
* Save final/001.mp4.
* Update final_file.
* Update status = "completed".

Functions:

* cut_clip()
* create_intro()
* burn_subtitles()
* create_outro()
* stitch_video()

Keep each function independent.

---

## Subtitle Handling

Use pysubs2.

* Load SRT.
* Extract only subtitle events inside clip timestamps.
* Shift timestamps so subtitles start at 0 in the clip.
* Generate temporary ASS subtitle file.
* Burn ASS into video with FFmpeg.
* If transcript already exists in project.json, regenerate subtitles from transcript timestamps.
